## Manual account setup

1. Regenerate the OAuth refresh token locally with the required YouTube and Drive
   scopes by running `python tools/get_refresh_token.py`. The script requests
   `youtube.upload`, `youtube.readonly`, and `drive.file`. Do not paste the token
   into source files or commit it.
2. In the same Google Cloud project, enable **Google Drive API** (and confirm
   **YouTube Data API v3** is enabled).
3. Set the Google OAuth consent screen publishing status to **In production**.
4. In repository Actions secrets, add or confirm `GEMINI_API_KEY`,
   `GEMINI_API_KEY1` (optional backup), `YT_CLIENT_ID`, `YT_CLIENT_SECRET`, and
   `YT_REFRESH_TOKEN`. `POLLINATIONS_TOKEN` is optional. The Drive fallback uses
   the refreshed `YT_REFRESH_TOKEN`; it has no separate Drive credential.
